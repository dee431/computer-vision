## 🚀 Project Overview

**AI Vision Assistant** is an intelligent Computer Vision application that uses **Deep Learning** to recognize real-world objects through a webcam and announces the detected objects using natural voice feedback.

Simply point your camera toward an object, and the AI detects what it sees and speaks the result aloud.

This project combines **Computer Vision**, **Artificial Intelligence**, **Object Detection**, and **Speech Synthesis** into one interactive assistant.

---

## 🎯 Project Goals

* Detect everyday objects in real time
* Recognize multiple objects in one frame
* Convert detected object names into speech
* Build an AI assistant for learning and accessibility
* Demonstrate modern Computer Vision using Deep Learning
